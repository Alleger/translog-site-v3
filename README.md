# Translog — вариант 3 «Cobalt» (мультиязычный)

Корпоративный синий стиль, ближе к эталону hegelmann.com. 6 языков, соцсети, быстрый запрос прямо на первом экране.

## Запуск

```powershell
npm install
npm run dev      # http://localhost:5173
npm run build    # готовый сайт в dist/
```

## Языки

EN, CS, PL, DE, UK (украинский), RU. Адрес содержит язык: `#/cs/contacts`, `#/de/services/express`.
При первом заходе язык берётся из браузера посетителя, выбор запоминается.

- Тексты: `src/i18n/en.js`, `cs.js`, `pl.js`, `de.js`, `uk.js`, `ru.js` — одинаковая структура
- Добавить язык: скопировать `en.js`, перевести, добавить строку в `src/i18n/index.js` (и флаг в `Flag.jsx`)
- Переводы сделаны автоматически — перед публикацией их стоит вычитать носителям языка

## Соцсети

`src/data.js` → `socials`. Сейчас заполнен только Instagram. У остальных пустой `url` —
иконка показывается бледной и без ссылки. Вставьте адрес, и иконка станет активной.

## Прочее

- `src/data.js` — телефоны, адреса, фото
- `src/styles.css` — цвета и шрифты в начале файла
- Форма открывает почтовый клиент (mailto); позже можно подключить n8n/CRM
- Публикация: `deploy.yml` → `.github/workflows/`, либо `dist/` в `public_html` на cPanel
